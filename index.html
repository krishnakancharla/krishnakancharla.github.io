IEEE Peer-Reviewed Publication DOI: 10.1109/ICACAT.2018.8933575 · ICACAT 2018

Handwritten Signature Recognition : A Convolutional Neural Network Approach

Krishnaditya Kancharla, Varun Kamble, and Mohit Kapoor · Published in IEEE International Conference on Advanced Computation and Telecommunication (ICACAT)

View on IEEE Xplore
Handwritten Signature Recognition is an important behavioral biometric used for numerous identification and authentication applications. Offline signature recognition handles a signature as a static image and predicts the author based on extracted visual features. Traditional methods predominantly employ template matching, comparing a test image against multiple specimen images—resulting in high memory consumption and time complexity. This paper proposes an offline signature recognition architecture using a Convolutional Neural Network (CNN) with OpenCV image preprocessing for noise removal, achieving high-accuracy multi-class classification with minimal training samples and winning 2nd Prize in the Departmental Project Competition.
